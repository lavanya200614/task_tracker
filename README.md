# Task Tracker

A simple project to add and view tasks.

## Installation
1. Clone the repository:
   git clone https://github.com/lavanya200614/task_tracker.git
2. Navigate into the folder:
   cd task_tracker

## Features
- Add tasks
- View tasks
- Simple clean structure

## Usage
Run the main file (example: main.py or index.html) to start the project.
